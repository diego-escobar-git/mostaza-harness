# search-code

Depends on: foundation, agent-retrieval, local-lmstudio-kaggle

## Purpose

Provide compact lexical source retrieval and conservative Python dependency navigation through the official run_command tool, with a disposable incremental index inside each task sandbox.

## Requirements

REQ-1: The active submission replaces the three native retrieval tools with a workspace-local search_code CLI while retaining official execution and historical reproducibility.
REQ-2: Search file paths, source text and Python symbols without embeddings, inference, Internet access or precomputed host graphs.
REQ-3: Build and refresh a bounded SQLite index automatically and return truthful, compact JSON with real source locations.
REQ-4: Demonstrate CPU portability and retrieval correctness independently of future Kaggle repair efficacy.

## Rules and constraints

AC-1: The active agent declares exactly run_command, read_file, edit_file, write_file, get_status and submit_patch as native tools. One official ADK skill supplies a bootstrap script; official skill-toolset discovery/load/run helpers may additionally be exposed and must be inventoried. No custom host tool, runtime/compiler/evaluator patch, neural search, model download or new inference is introduced. Historical experiment sources, manifests and retained evidence remain byte-identical and their native registry compatibility remains available.

AC-2: The packaged skill contains one authoritative standalone Python search_code implementation, runnable on Python 3.12 and 3.13 using only the standard library. The official compiler, SkillToolset and AdkSandboxCodeExecutor must execute it in a real disposable subprocess sandbox. Bootstrap requires an explicit absolute sandbox workspace root, copies the exact CLI bytes atomically to a versioned private temporary directory outside that root, returns the quoted run_command invocation, and may perform the first query. A later native run_command invocation succeeds after transient skill resources disappear. Executable/cache isolation binds canonical workspace, source version and index schema; symlinks, foreign cache ownership and cross-workspace reuse fail closed. No executable, database, lock or bootstrap residue appears in the submitted diff.

AC-3: Search accepts literal bounded query text and optional workspace-relative path filters; it indexes visible regular UTF-8 source/text files without following symlinks or escaping the workspace. Exclude .git, environments, caches, binary/generated/vendor bulk and explicit solution/reference/test_patch artifacts; do not ingest task metadata, verifier-only material or host graph/embedding stores. FTS5 lexical ranking combines exact path/name matches with token/source matches and deterministic tie breaking. Python AST extraction includes modules, classes, nested functions, methods and async definitions. Each symbol has a unique ID derived from relative path, qualified name, kind and definition location and exposes actual start/end lines. Duplicate names never silently select a suffix match. Missing FTS5 is an explicit unavailable capability with a safe lexical-shell fallback instruction, never a false successful empty index.

AC-4: The lightweight graph records containment, statically resolvable imports and conservative call edges. Neighbor queries distinguish callers/callees/imports/containment, and subgraph queries return the induced graph of explicit seeds plus a bounded expansion (default one hop, maximum two). Resolve same-module names, lexical nesting, import aliases and package-relative imports where unique; unresolved dynamic dispatch, wildcard imports and ambiguous symbols remain explicit unresolved data, never fabricated edges. Duplicate definitions and async/nested scopes have fixtures with exact expected nodes/edges. Non-Python text remains lexically searchable without a claim of semantic graph coverage.

AC-5: Every operation checks index/schema/source readiness and reconciles the current workspace before answering. Content fingerprints detect equal-size/equal-mtime edits as well as add/delete/rename and changes from edit_file, write_file and run_command. Reparse only changed files; refresh resolution for affected dependents, removing stale cross-file edges. Serialize writers with a bounded lock wait, use atomic committed generations, and never present a partial/interrupted/stale generation as current. Concurrent modification causes a bounded retry or an explicit incomplete/busy response. Parse failures preserve current lexical text and report graph incompleteness; removed or broken definitions never retain old graph edges. Corrupt/schema-incompatible caches rebuild safely; interrupted builds recover on the next call.

AC-6: All ordinary results, invalid arguments, ambiguity, unavailable capability, timeout and truncation responses use schema_version=1 JSON. The serialized stdout is at most 4500 characters including newline and stderr is empty for handled failures, fitting the native default 5000-character stream limit. Serialize then drop whole entries/snippets until valid JSON fits; report truncated/incomplete and counts. Return status, mode, workspace-relative locations, bounded results/nodes/edges, index generation and refresh counters, unresolved/omitted counts, and duration. Never return an unbounded traceback or source dump. Defaults: 8 results, 20 maximum; 40 nodes and 80 edges maximum; query length 512 characters; 45-second cooperative operation deadline and bounded lock wait. Large/binary/unreadable/excluded files and indexing limits are explicit counts/reasons. File and source limits are 1 MiB per file, 50000 eligible files and 256 MiB cumulative source bytes; reaching a bound returns incomplete, not complete.

AC-7: The host packager permits only the selected skills/search-code/SKILL.md and skills/search-code/scripts/search_code.py in addition to the existing YAML/prompt closure, validates the declared single skill and rejects extra code, traversal, symlinks, duplicate/unknown tools and resource injection. Deterministic ZIP and generated delivery notebook contain exactly the same approved source bytes; no credentials/data/cache/development files. The real pinned directory/schema/compiler accepts the active delivery and frozen E0/E1 packages. Active instructions teach bootstrap, quoting, bounded search/graph use, refresh behavior and plain-shell fallback; preserve model/generation settings and timeout_seconds=60, max_time_minutes=5, max_tool_calls=20, max_turns=50. Bootstrap and cold indexing consume the existing wall-clock budget; document actual helper/native budget accounting without changing official enforcement.

AC-8: Deterministic CPU checks cover all prior criteria, adversarial file/cache/packaging inputs and native edit/write/command refresh. A source-only benchmark uses the five locally available snapshots (requests_7205, requests_7315, requests_7502, fastapi_15589, rich_3061), with no solution/test-patch queries, plus synthetic nested/async/ambiguous/non-Python cases. A small deterministic query set derived only from visible source tests exact symbol/location retrieval in the top 5 and graph fixtures test exact supported edges. Record per-snapshot cold bootstrap/index/search, warm search and single-file refresh: each cold operation <=45 s, warm <=3 s, refresh <=10 s, peak child RSS <=256 MiB and database <=128 MiB. Unchanged warm runs reparse zero files; a single-file content edit reparses only that file while dependent edges update. Missing fixtures/interpreters or exceeded limits fail the CPU gate, never silently skip. Validate actual Python 3.12 execution and subprocess path behavior; inspect pinned Docker /workspace command semantics and test absolute/path-with-spaces contract fixtures without starting/changing Docker or Kaggle sessions. Reports explicitly distinguish measured local CPU behavior, source-reviewed Docker mapping and unexecuted Kaggle efficacy.

## Interfaces and data contracts

The same scripts/search_code.py supports bootstrap, search, neighbors, subgraph and status subcommands, all with --root ABSOLUTE_WORKSPACE. Bootstrap also accepts --query; search takes --query and optional --path/--limit; neighbors takes --symbol and --edge-kind/--limit; subgraph takes repeatable --symbol and --hops; status refreshes readiness. Symbol ambiguity returns bounded candidates with IDs. Bootstrap returns executable_path and a shell-quoted command. Retrieval returns relative paths and inclusive start_line/end_line; graph edges include source, target, kind and supporting source location. Internal SQLite stores schema/source/workspace identity, file content hashes, symbols, FTS text, unresolved references and directed edges. The database is derived disposable state, never a product source or submission artifact.

## Out of scope

Neural/vector similarity, learned ranking, full language-server accuracy, non-Python semantic graphs, global daemons, official-runtime modifications, frozen experiment changes, public services, model execution/downloads, GPU or Kaggle session/submission changes and efficacy claims on all 129 tasks.
